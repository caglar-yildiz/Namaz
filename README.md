# Namaz

Türkiye odaklı sade namaz vakti ve dini gün hatırlatıcı Android uygulaması.

## MVP
- İl/ilçe seçimi ve namaz vakitleri (doğrulanmış veri sağlayıcısı entegrasyonu bekliyor)
- Kullanıcı kontrollü namaz bildirimleri
- Kandil ve dini günler takvimi
- Ana ekran widget'ı

## Teknoloji
Kotlin, Jetpack Compose, Android SDK. İlk aşamada hesap veya backend gerekmiyor.

## Durum
Proje iskeleti oluşturuluyor. Gerçek namaz vakti verisi doğrulanmadan örnek saatler üretmeyin. Bildirim ve widget entegrasyonları henüz tamamlanmadı.
